# PERIMETRO PROTETTO — REG-01
#
# Un percorso per riga, preceduto dal MODO. Righe vuote e righe con # sono commenti.
#
#   SEMPRE     la catena serve anche solo per CREARE il file.
#              Vale per le migrazioni: una migrazione nuova E' il rischio.
#   MODIFICA   la catena serve per modificare, rinominare o cancellare.
#              Creare un file nuovo qui e' libero.
#
# PERCHE' LA DISTINZIONE. La prima versione pretendeva la catena anche per creare
# un collaudo nuovo o uno script nuovo: bloccava il lavoro ordinario e avrebbe reso
# il metodo odioso entro un giorno. Il rischio vero non e' aggiungere copertura, e'
# TOGLIERLA: un collaudo nuovo puo' solo aggiungere controlli, uno modificato puo'
# rimuoverli in silenzio. Le migrazioni sono l'eccezione perche' li' la creazione
# muove i dati.
#
# QUESTO FILE E' DENTRO IL PERIMETRO CHE DESCRIVE: toglierne una riga richiede
# la stessa catena di una migrazione. Senza, il primo modo di aggirare REG-01
# sarebbe cancellare la riga che protegge cio' che si vuole toccare.
